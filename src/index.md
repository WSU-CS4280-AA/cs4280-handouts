# CS 4280 - Computer Graphics: Hands-On Handouts

Each handout works through that
module's topic from first principles, with fresh runnable code you can read
top to bottom, edit in place, and see change live. Modules 1–3 build the
JavaScript and math foundations; WebGPU itself starts in Module 4, per the
course schedule.

These handouts teach the *techniques* behind each module's topic — they are
not solutions to the graded assignments.
